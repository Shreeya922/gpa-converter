
# Smart GPA Converter

A Python-based GPA Converter built using Streamlit.

## Features

1. Quick Percentage to GPA Converter
2. Advanced GPA Calculator
3. Custom Grading System
4. Subject-wise Grade Calculation
5. Weighted GPA Calculation
6. Downloadable Academic Report

## Technologies

- Python
- Streamlit
- Pandas

## Installation

Install the required libraries:

py -m pip install -r requirements.txt

## Run Application

py -m streamlit run main.py
